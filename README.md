# Advanced Attention Time Series Forecasting

This project implements multivariate time series forecasting using an Encoder-Decoder LSTM with Attention mechanism.

## Features
- Multivariate dataset (3 features)
- Encoder-Decoder Attention model
- Hyperparameter grid search
- Metrics: MAE, RMSE, MAPE
- Interpretability analysis

## Run
```bash
pip install -r requirements.txt
python main.py
