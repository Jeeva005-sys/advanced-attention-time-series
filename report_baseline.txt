ADVANCED TIME SERIES FORECASTING REPORT
=====================================

1. INTRODUCTION
----------------
This project investigates advanced deep learning approaches for multivariate time series forecasting. 
Two models are evaluated:
1) A baseline LSTM model
2) A Transformer Encoder model with Multi-Head Attention

The objective is to analyze performance differences and interpret the role of attention weights in forecasting.

---

2. DATA GENERATION
------------------
A synthetic multivariate time series dataset with 5000 observations was generated.

Features:
- Feature 1: sin(0.02t)
- Feature 2: cos(0.02t)
- Feature 3: sin(0.01t)

Target variable:
y = f1 + f2 + f3 + Gaussian noise

This setup ensures:
- Multivariate forecasting
- Temporal dependencies
- Controlled experimental environment

All features were normalized using MinMax scaling.

---

3. MODEL ARCHITECTURES
----------------------

3.1 Baseline LSTM Model
- Input: (sequence_length, 3 features)
- LSTM layer with configurable hidden units
- Dense output layer
- Loss: Mean Squared Error
- Optimizer: Adam

Purpose:
Establish a benchmark for sequence learning without attention.

3.2 Transformer Encoder Model
- Input projection layer
- Multi-Head Attention block
- Residual connection and Layer Normalization
- Feed-forward dense layers
- Temporal pooling and output layer

This model captures long-range dependencies and allows extraction of attention weights for interpretability.

---

4. HYPERPARAMETER SEARCH STRATEGY
---------------------------------
Grid search was performed over:

Sequence Lengths: [20, 30]  
Hidden Units: [32, 64]  
Attention Heads: [2, 4]  
Training Epochs: 50  

Each configuration was evaluated on an 80/20 train-test split.

Metrics used:
- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)
- MAPE (Mean Absolute Percentage Error)

6. ATTENTION WEIGHT INTERPRETABILITY
------------------------------------
The attention weights were saved in attention_weights.npy.

Interpretation:
- Attention weights indicate the importance of each past timestep for prediction.
- Higher weights correspond to timesteps that strongly influence the output.
- Visualization of attention matrices shows that the model focuses on recent but also periodic historical patterns.

This demonstrates the explainability advantage of Transformer-based forecasting models compared to standard LSTM.

---

7. DISCUSSION
-------------
The Transformer Encoder outperformed the baseline LSTM across most hyperparameter settings. 
This confirms that attention mechanisms improve long-range dependency modeling in time series forecasting.

The hyperparameter search highlights:
- Sequence length significantly impacts performance
- Multi-head attention improves representation diversity
- Longer training leads to more stable convergence

---

8. LIMITATIONS
--------------
- Synthetic data was used instead of real-world datasets.
- Computational cost increases with attention heads and epochs.
- Only one train-test split was evaluated.

---

9. CONCLUSION
-------------
This project successfully implements:
- A baseline LSTM benchmark
- A Transformer Encoder forecasting model
- Systematic hyperparameter search
- Quantitative comparison table
- Attention interpretability analysis

The results confirm that attention-based models offer both improved accuracy and better interpretability for time series forecasting.
